# CS409 MP3: Task Management API

A task management REST API built with Node.js 24, Express 5, and Mongoose 9.

The API provides user and task CRUD endpoints under `/api`, JSON query parameters, server-side validation, and transactional synchronization of task assignments and pending-task lists.

The integration suite covers CRUD operations, validation, queries, reference consistency, transaction rollback, concurrent updates, and CORS.
